# Font Studio

מנהל, ארכיון ותצוגת גופנים ל-Windows, עם ממשק עברי מימין לשמאל.

## בניית EXE בלי Python במחשב שלך
1. פתח את המאגר ב-GitHub והעלה את הקבצים האלה לענף `main` (או `master`).
2. עבור ללשונית **Actions** והפעל את **Build Font Studio for Windows** באמצעות **Run workflow**.
3. בסיום מוצלח, פתח את הריצה והורד את `FontStudio-Windows-x64` תחת Artifacts. בתוך ZIP זה נמצא `FontStudio.exe`.

## הפעלה מקומית לצורכי פיתוח
Python 3.12 נדרש לפיתוח בלבד:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python font_studio.py
```

## נתונים ואחסון
- מאגר הגופנים נמצא בתיקיית `FontLibrary` לצד קובץ התוכנה (`FontStudio.exe`).
- מסד הנתונים, ההגדרות והגיבויים נמצאים בתיקיית `FontStudioData` לצד קובץ התוכנה.
- **אפשר להעביר את Font Studio למחשב אחר או לכונן אחר:** יש להעביר יחד את `FontStudio.exe`, את `FontLibrary` ואת `FontStudioData`. בהפעלה הבאה התוכנה סורקת אוטומטית את `FontLibrary`, מזהה קבצים לפי SHA-256 ומעדכנת במסד הנתונים נתיבים ישנים לנתיבים החדשים. אין צורך לייבא מחדש את הגופנים.
- אם התיקיות אינן ניתנות לכתיבה, התוכנה עשויה להשתמש במיקום חלופי תחת `%LOCALAPPDATA%\\FontStudio`; במקרה כזה הנתונים אינם עוברים יחד עם קובץ ה-EXE, ויש להעביר גם את התיקיות מהמיקום החלופי.
- גיבויים אוטומטיים של מסד הנתונים וההגדרות נשמרים בתיקיית `Backups`; קובצי הגופנים אינם נכללים בגיבוי.

## הערות
- סריקה ראשונית סורקת את תיקיית המאגר של Font Studio. ייבוא תיקיות נוספות נעשה ידנית.
- מסנן שפה מציג רק משפחות שבהן נמצאו גליפים מהכתב שנבחר (עברית, לטינית/אנגלית, ערבית, קירילית, יוונית, סינית, יפנית או קוריאנית). הסיווג מבוסס על מפת התווים של קובץ הגופן, ולא על שם הקובץ. גופן שתומך בכמה כתבים יופיע בכל השפות הרלוונטיות.
- לאחר עדכון מגרסה ישנה, מומלץ לבצע סריקה ידנית פעם אחת כדי להשלים מטא־נתוני שפה לרשומות שכבר קיימות.
- הסריקה מתבצעת ברקע; קובץ גופן פגום מדולג בלי לעצור את כל התהליך.
- התקנה זמינה ב-Windows בלבד ודורשת אישור לפני התקנת כל משקלי המשפחה.
- זהו בסיס עובד ראשוני, לא מוצר חתום או מאומת במלואו. לפני הפצה רחבה יש לבצע בדיקות התקנה, הסרה, הרשאות, קבצים משתנים וטעינת גופנים במחשבי Windows שונים.

## תיקוני תצוגה והתקנה
- תצוגת כל משפחה טוענת את קובץ הגופן עצמו דרך Qt, כך שהדוגמה מוצגת בגופן גם כשהוא אינו מותקן ב-Windows.
- חלון "התנסות" הוא עורך חי: הטקסט שמקלידים מוצג ישירות במשקל הגופן שנבחר, בלי תיבת הקלדה נפרדת בגופן מערכת ותצוגה משנית.
- כפתור "צבע התצוגה" מאפשר לבחור צבע לתצוגות המקדימות; הבחירה נשמרת בהגדרות.
- בכל שורת משפחה מוצג מצב "מותקן" או "לא מותקן" לפי האינדקס, וכן "חסר קובץ" כשקובץ המקור אינו זמין. כפתור "התקנה" נשאר זמין למשפחות שלא הותקנו.
- תוקנה הוספה כפולה של אפשרויות מסנן השפה.

הערה: מצב ההתקנה מבוסס על נתוני האינדקס של Font Studio. במימוש הבא יש להוסיף אימות מול רישום הגופנים של Windows כדי לזהות גם התקנות שנעשו מחוץ לתוכנה.
